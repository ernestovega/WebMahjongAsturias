Duplicate

Duplicate is a way to play, not a new variant. All the tables play the same hands.

What it is

The Duplicate format aims to reduce the effect of luck. All the tables play exactly the same deals, and the result of each player is compared with the results the others got with those same tiles. It works like duplicate Bridge.

The Mahjong International League (MIL (opens in a new tab)) promotes this format to make Mahjong a competitive mind sport. You can read more in Mahjong as a mind sport.
